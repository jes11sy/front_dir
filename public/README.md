# Public Assets Conventions

This directory follows a fixed layout:

- `images/` - static images used by UI and metadata (`logo_*`, `favicon`, `pwa_*`)
- `fonts/` - local font files
- `video/` - static videos for pages/components

Naming rules:

- use lowercase file names with dashes (example: `hero-banner.webp`)
- avoid nested duplicate folders (example: `images/images/*`)
- keep large binaries in dedicated subfolders to simplify cleanup and review
